# Security

CYVORA does not trade live. Do not send a seed phrase, a private key, a wallet password, an API token, or a database URL to this repository.

GitHub issues and the wiki are public. Put vulnerability reports somewhere other than a public issue if they describe a reachable secret. The application binds to loopback and does not accept a live execution mode.

`.env` is gitignored. `.env.example` contains placeholders only.
